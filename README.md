# Akıllı Ev Cihaz Yönetim Sistemi

Nesne Yönelimli Programlama – 1. hafta lab ödevi.

C# konsol uygulaması ile lamba, klima ve güvenlik sistemi cihazları listelenebilir, eklenebilir, açılıp kapatılabilir. Aynı kimlik iki kez eklenemez.

## Çalıştırma

.NET 8 SDK ile proje klasöründe:

```bash
dotnet run
```
